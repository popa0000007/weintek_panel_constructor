# Конструктор панели — инструкция (версия 1.0)

Конструктор — программа в браузере для окон панели Weintek на JS-объектах. Элементы двигаются мышкой,
теги выбираются из списка, опросы ПЛК Siemens считаются сами. Код JavaScript писать и читать не нужно.

**Файл:** `hmi/constructor/Конструктор_панели.html` — открыть двойным щелчком (Chrome, Edge, Firefox).
Интернет не нужен. Проект сохраняется в этом браузере сам; для переноса — кнопка «Сохранить».

## Как это устроено

- Одно окно конструктора = один JS-объект EasyBuilder (как ваши окна 10–18): обычно X0 Y48, 1024×664.
- Холст в конструкторе — это настоящий код панели (то же ядро `hmi/js/src/core.js`), запущенный в браузере.
  Что видите — то и будет на панели (шрифт панели может чуть отличаться).
- На панель уходит два текста: **код** (вкладка «Исходный код») и **конфигурация** (кнопка «Шаблон…»).

## Первый запуск

Откроется пример — **мнемосхема ГЦУ**, перенесённая из окна 10/16 один в один, и окно-образец
«свои данные (DB200)» со своим всплывающим окном мотора. Можно сразу двигать элементы и смотреть.
«Новый» — чистый проект; «Пример» — вернуть пример.

## Модель панели и рабочая область

Кнопка **«Панель»**: выбор модели Weintek (cMT2078X, cMT2108X2, cMT2128X, cMT2158X, cMT3072XH, cMT3092X, cMT3152X, cMT3162X, MT8071iP, MT8102iP, MT8121XE, MT8150XE или «вручную»).
Модель задаёт разрешение экрана; размер окна конструктора = экран минус верхняя полоса и нижнее меню (по умолчанию 48 и 56, как в проекте ГЦУ).
Флажки: применить размер ко всем окнам и (необязательно) пропорционально сдвинуть/растянуть элементы — шрифты не меняются, вид надо проверить.
Для моделей MT8121XE и MT8150XE разрешение не подтверждено datasheet — сверьте с вашей панелью. При высоте области меньше 460 px экранная клавиатура не помещается.

## Свои технологические элементы (символы)

Кнопка **«Символы»** (или «Элементы» → «Мои символы» → «Библиотека…»). Символ — это набор фигур (прямоугольник, эллипс, многоугольник, ломаная, текст)
и таблица состояний «значение тега → название, заливка, контур, цвет текста, мигание».
- Цвета фигур: `#RRGGBB` либо `@f` (заливка состояния), `@s` (контур), `@c` (цвет текста). В тексте `@lb` — подпись элемента, `@st` — название состояния.
- Фигуру можно показывать только при некоторых значениях тега («показывать при значениях»).
- **Импорт SVG** (файл или вставка текста): rect, circle, ellipse, line, polygon, polyline, path (кривые → ломаные), text. Можно сразу заменить цвета на `@f`/`@s`.
- Готовый символ перетаскивается на холст как обычный элемент (тип «Свой символ»): свойства — символ, тег состояния, подпись; доступны «Состояния», «Видимость» и «При нажатии».
- Размер на холсте меняется, фигуры масштабируются. На панель уходят только используемые символы. Пример — «Мешалка» в окне-образце.

## Порядок работы

### 1. Данные ПЛК (кнопка вверху справа)

Здесь блоки данных (DB) и их поля — это и есть теги.

**Импорт из TIA Portal (лучший способ — смещения посчитаются сами):**
1. В TIA: ПКМ по блоку данных → *Generate source from blocks* → сохранить файл.
2. В конструкторе: «Данные ПЛК» → «Импорт…» → выбрать файл (или открыть его блокнотом и вставить текст).
3. Если DB использует свои типы (UDT, например `TDIData`) — сгенерируйте исходник и для них (то же меню, ПКМ по типу в «PLC data types»; DB и типы можно выделить вместе, если TIA разрешает, либо по отдельности) и вставьте **всё подряд в одно поле**: порядок не важен — DB и `TYPE … END_TYPE` разбираются вместе. Можно вставить и готовые файлы проекта (например `plc/0_IO_Lib.scl` + `plc/5_GCU_HMI.scl`).
4. Отметьте нужные блоки, впишите **номер DB** (свойства блока в TIA → General → Number), «Импортировать».
5. Сверьте 2–3 смещения со столбцом *Offset* в редакторе DB в TIA.

Также можно вставить файл тегов EasyBuilder (`hmi/GCU_EB_Tags.csv`) или таблицу из Excel (Имя ⇥ Тип ⇥ Смещение ⇥ Комментарий).
Или добавить поля вручную («+ поле», затем «Смещения по порядку» — как TIA в неоптимизированном DB).

**Колонки таблицы полей:**

| Колонка | Что это |
|---|---|
| Запись | Отметьте, если панель пишет в это поле (кнопки, поля ввода). Без отметки тег только читается |
| Демо | Значение в демо-режиме и в «Просмотре» |
| Имитация | Как меняется в демо: волна, мигание, пила |
| Масштаб | Сырое мин/макс → инженерное мин/макс (например 0 / 27648 → 0 / 100 %) |

**Важно для ПЛК:** DB должны быть **неоптимизированными** (снять *Optimized block access*), в CPU включён PUT/GET
(как для DB100/DB101).

**Связь с ПЛК** (слева в том же окне): имя устройства как в EasyBuilder (`Siemens S7-1200/S7-1500`),
«Слов за запрос» — не больше «Макс. размер команды чтения» драйвера (90 по умолчанию; у вас ограничение 100).

**Опросы** настраивать не нужно. Конструктор собирает теги, которые использует окно, в непрерывные участки
каждого DB и читает их с периодом DB («Опрос, мс»). Список опросов — внизу окна «Данные ПЛК».

### 2. Элементы

Перетащите элемент из палитры слева на холст (или нажмите на него — появится в центре). Справа — свойства.

| Группа | Элементы |
|---|---|
| Основные | текст, значение, окно значения (как LT-1), панель, круг, линия, трубы, стрелка, дата и время |
| Технология | задвижка (гориз./верт.), насос/мотор, ёмкость с уровнем и отметками, столбик, датчик PT/LT, гидроциклон, карточка насоса ГЦУ |
| Индикация | лампа, многосостояние (значение → текст и цвет), список сообщений, тренд, строка аварий ГЦУ |
| Управление | кнопка (любое действие), кнопка «открыть окно», «закрыть», кнопка «пока нажата» (толчок), поле ввода |

**Тег** выбирается в поле с кнопкой ⋯ — список всех тегов с адресами и комментариями (поиск по имени, адресу,
комментарию). Красная рамка — такого тега нет.

**Состояния** (у большинства элементов): «если тег = …, то заливка красная / текст другой / мигать / скрыть».
**Видимость**: элемент виден только при условии. **При нажатии**: любой элемент можно сделать кнопкой.

**Действия кнопок:** записать значение в тег · переключить бит · ввести число с клавиатуры · открыть своё окно ·
закрыть окно · команды ГЦУ/насосу/задвижке · окно задвижки/насоса ГЦУ · сброс всех аварий ГЦУ.
К любому действию: подтверждение «ДА/НЕТ», пароль инженера, сообщение, запись в журнал событий.

### 3. Данные ГЦУ (встроенные)

Теги `gcu:…` — это DB100/DB101, которые ядро панели уже разбирает (уровень, давление, режимы, насосы, 18 задвижек,
давления линий и воздуха, аварии). Задвижки, насосы и гидроциклоны с «Данные: ГЦУ» по нажатию открывают готовые
окна задвижки и насоса. Уставки DB101 для записи — `gcuset:…` (поле ввода), ручное задание — `gcuspd:1/2`.

### 4. Свои всплывающие окна

«Окна» → «+ Своё окно». Окно с заголовком и крестиком поверх экрана, как окно задвижки.
Открывается кнопкой с действием «Открыть своё окно». **Номер #:** в тегах и текстах окна пишите `#` вместо номера,
например `MY_DB.Motor[#].Run`, заголовок `Мотор #`. Кнопка с номером 2 откроет окно мотора 2 — одно окно на все моторы.

### 5. Проверка: ▶ Просмотр

Элементы нажимаются, окна открываются, как на панели. Справа — память имитатора ПЛК: меняйте значения тегов и
смотрите, что панель пишет в ПЛК (адрес и слова). Данные ГЦУ имитируются демо-режимом ядра.

### 6. Экспорт в панель

Кнопка «Экспорт в панель» → выбрать окно:

1. EasyBuilder: окно → Объекты → JavaScript → **JS-объект**, профиль X/Y/ширина/высота — как написано в окне экспорта.
2. Вкладка «Исходный код»: удалить всё, вставить код («Копировать код») → «Компиляция».
3. «Конфигурирование» → «Шаблон…» → удалить всё → вставить конфигурацию → OK. Число записей должно совпасть с подсказкой.
4. Без ПЛК: в «Шаблон…» `"demo": false` → `true` — окно покажет демо-значения. Потом вернуть `false`.

Изменили окно — вставьте **код** заново. Конфигурацию — только если менялись теги, DB или адреса.

Полоса «Размер кода» — лимит JS-объекта около 100 КБ. Мнемосхема ГЦУ занимает ~80 КБ. Если окно не помещается —
разделите его на два или уберите неиспользуемые элементы.

## Мышь и клавиши

| Действие | Как |
|---|---|
| Выделить несколько | Shift + щелчок, или рамка по пустому месту |
| Двигать без привязки к сетке | держать Alt |
| Только по горизонтали/вертикали; размер с пропорциями | держать Shift |
| Сдвиг на 1 / на шаг сетки | стрелки / Shift + стрелки |
| Отмена / повтор | Ctrl+Z / Ctrl+Y |
| Копировать / вставить / дублировать / удалить | Ctrl+C / Ctrl+V / Ctrl+D / Delete |
| Группа / разгруппировать | Ctrl+G / Ctrl+Shift+G |
| Масштаб | Ctrl + колесо мыши |
| Меню | правая кнопка мыши |
| Свойства окна | щелчок по пустому месту холста |

Выравнивание нескольких элементов — панель над холстом. Слои (вкладка слева): порядок, скрыть в редакторе, заблокировать.

## Ограничения (знать заранее)

- Генерируются адреса только DB (`DBn`). Для областей M/I/Q — галочка «адрес вручную» у DB: выберите в «Шаблон…»
  Адрес начала области и вставьте его строку. Запись в такие теги недоступна. Проще — копировать данные в DB в ПЛК.
- Запись бита: панель читает слово, меняет один бит и пишет слово обратно. Если ПЛК в это же мгновение меняет
  соседний бит этого слова, изменение ПЛК может потеряться. Для команд надёжнее Int-код, который ПЛК обнуляет
  (как команды в DB100), или отдельное слово под биты панели.
- Окна 11–15, 17, 18 перенесены в пример как окна конструктора (источники — `src/make_*.js`; что перенесено не точно — `examples/GAPS_*.md`). Оригинальный код — `hmi/js/`.
- Картинки (PNG/SVG) в JS-объекте не используются — символы рисуются кодом.

## Где что лежит (для разработчика)

| Файл | Что |
|---|---|
| `Конструктор_панели.html` | готовый конструктор (собран, открывать его) |
| `build.py` | сборка: `python hmi/constructor/build.py` — берёт текущее `hmi/js/src/core.js`. **После любой правки ядра пересобрать** |
| `src/runtime.js` | код панели для элементов (рисование, опрос DB, запись, свои окна) |
| `src/export.js` | экспорт, план опросов, адреса EasyBuilder, импорт SCL/CSV/таблиц |
| `src/editor.*` | редактор |
| `src/make_example.js`, `src/make_*.js` | пример: мнемосхема + окна насосов, уставок, аварий, трендов, I/O, пульподелителя (`node src/make_example.js` → `examples/gcu.json`, потом `build.py`) |
| `src/symlib.js`, `src/panel.js` | библиотека символов; выбор модели панели |
| `projects/` | сюда класть сохранённые проекты (`*.constructor.json`) |
